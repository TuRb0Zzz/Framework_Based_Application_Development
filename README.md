# Сервис учёта долгов
## Назначение
Объеденить все долги в одном месте для удобства их просмотра и соблюдения сроков.
## Целевая аудитория
Люди, имеющие долги и нуждающиеся в их быстром просмотре.
## Предметная область
Учёт и контроль долгов. Система работает с долгами, их сроками, временем до погашения, плятежах и просрочках.
## Основные сущности
- Пользователь
- Долг
- Платеж
## Основные функции
- Добавления долга и сроков
- Уведомление о скором сроке оплаты
- Ведение графика платежей
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация проекта
